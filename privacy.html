Política de Privacidad

Última actualización: 2026-08-25

"contentcreator" (también referida como "rootbusinessai") es una herramienta de uso estrictamente personal, operada por su único usuario y propietario, para publicar contenido en su propia cuenta de TikTok.

Qué datos se usan

La aplicación almacena localmente, en la computadora del propietario, el token de acceso (access token / refresh token) que TikTok emite al autorizar la app mediante OAuth. Ese token se usa exclusivamente para publicar videos en la cuenta de TikTok del propio propietario.

Qué datos NO se recolectan

La aplicación no recolecta, almacena ni comparte datos de ningún otro usuario. No hay base de datos, servidor ni servicio de terceros que reciba esta información: todo el procesamiento ocurre localmente.

Compartición de datos

Los datos no se venden ni se comparten con terceros. El único destino de la información es la API oficial de TikTok, usada para publicar el contenido que el propietario aprueba manualmente.

Revocar acceso

El propietario puede revocar el acceso de esta app a su cuenta de TikTok en cualquier momento desde la configuración de su cuenta de TikTok (Configuración → Seguridad y permisos → Aplicaciones conectadas).
